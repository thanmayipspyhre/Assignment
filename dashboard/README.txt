Pressure Performers dashboard
=============================

Open index.html in a browser to view it locally (double-click works; no server needed).

Files
  index.html, styles.css, app.js   the page
  data.js                          all numbers and player text shown on the page
  downloads/                       Methodology_Report_Extended.docx and Submission_Bundle.zip (the two download buttons)
  players/                         put player photos here (see players/README.txt)

To get a shareable link (pick one)
  1. Netlify Drop: go to app.netlify.com/drop and drag this whole folder onto the page. You get a link in about a minute.
  2. GitHub Pages: put the folder in a repository, then Settings > Pages > deploy from the main branch.
  Anyone with the link can see the page and download both files, so check you are happy for the submission to be public first.

Dark and light themes follow the viewer's system setting; the moon button switches manually.
